# Install Casa

Casa runs on Obsidian desktop: Mac, Windows and Linux. It does not run on Obsidian mobile.

## From Obsidian (recommended)

1. Open **Settings > Community plugins**.
2. If community plugins are off, turn them on.
3. Select **Browse** and search for **Casa**.
4. Select **Install**, then **Enable**.

The room opens in a new tab the first time. Later, open it in any of these ways:

- the house icon in the left ribbon (**Open Casa**);
- the command palette: **Casa: Open room** shows the open room, or opens one in a new tab;
- the command palette: **Casa: Open room in a new tab**.

Updates arrive the same way: **Settings > Community plugins > Check for updates**.

## From a GitHub release

1. Open the [latest release](https://github.com/adrianofontanari/casa/releases/latest).
2. Download `main.js`, `manifest.json` and `styles.css`.
3. Put them in `<your vault>/.obsidian/plugins/casa/`. Create the folder if it does not exist. If you renamed your vault's config folder, use that name instead of `.obsidian`.
4. Restart Obsidian, then enable Casa in **Settings > Community plugins**.

With a manual install, Obsidian does not update Casa for you. Repeat these steps for a new version.

## Remove Casa

**Settings > Community plugins > Casa > Uninstall.** Your notes stay as they are. The notes Casa made for you (`Casa/Post-its.md` and `Casa/Quotes.md`, if you added a post-it or a quote) stay in your vault until you delete them.
