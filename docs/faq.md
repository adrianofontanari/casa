# FAQ

**Is Casa free?**
Yes. The room in this plugin is free and asks for no payment.

**What are the packs?**
Focus, Orbit, Living and Lighthouse: more rooms and objects, coming later. They are not on sale. [Join the waitlist](https://casa.adrianofontanari.com/#notify) for one email when they are out. The free room stays free.

**Does it work on Windows and Linux?**
Yes, anywhere Obsidian desktop runs.

**Obsidian mobile?**
Not yet. Casa runs on Obsidian desktop only.

**Do I need other plugins or a template?**
No. Casa reads your Daily notes, Periodic Notes or Journals settings if you have them (the plugins do not need to be installed), and uses `Daily/YYYY-MM-DD.md` otherwise. See [First run](first-run.md).

**Does Casa change my notes?**
Only when you do something in the room: write a goal, tick, add or edit a task, add, move or remove a post-it, add a quote. Opening the room changes nothing. The formats are in the [README](../README.md#how-casa-reads-and-writes-your-notes).

**Where does the goal go?**
Where you already keep it: a `goal:` property, a line under a heading with "goal", "focus" or "today", or a `Goal:` line. If there is none, Casa adds `## Today's goal` near the top of today's note.

**Will it see my tasks?**
Checkboxes in today's daily note, and tasks anywhere in the vault with a Tasks plugin date (`📅` due or `⏳` scheduled). Empty checkboxes and checkboxes in code blocks are ignored. The Tasks plugin is not needed.

**Does it work offline?**
Yes. The room, your goal, tasks, post-its and quotes work without internet. Weather and calendar show their last answer and refresh when you are back online.

**Which calendars work?**
Any calendar with an ICS link: Google, Outlook, iCloud and most others, recurring events included. See [Calendar](calendar.md).

**Why is the webcam the sea?**
The default webcam is a NOAA buoy camera 18 nautical miles off San Francisco: public domain, so Casa can show it. Paste the image link of another webcam in settings, or turn the webcam off.

**Does Casa use AI?**
No. Casa never sends your notes to an AI.

**Can I use it on a work computer?**
Casa is listed in Obsidian's community plugins and its code is public in this repository, so your IT team can read it. With every online source off, Casa makes no network request. See [Privacy](privacy.md).

**Will it slow my computer down?**
The room pauses whenever you cannot see it, and each picture repaints only when it changes. Calm mode stops the animations.

**Can it be calm and plain?**
Yes. Turn on calm mode and hide the buddy in [Settings](settings.md).

**Is Casa made by Obsidian?**
No. Casa is an independent plugin by [Adriano Fontanari](https://adrianofontanari.com). It is not affiliated with Obsidian.

**Can I fork it or reuse the pixel art?**
Not without written permission. You can read the code and report issues. See the [licence](../LICENSE).
